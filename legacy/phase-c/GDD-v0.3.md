## 1. コンセプト

**一言**: GI × Dark Forest × FRLG — ZKで全てが隠された島のカード奪い合いPvPゲーム

**エレベーターピッチ**:
3人のプレイヤーがFog of Warに包まれた島に放り込まれる。5種のカードを全て集めればクリア。ただし:
- 誰が何を持っているか見えない（ZK手札）
- 誰がどこにいるか見えない（ZK位置）
- 各カードは特定のエリアでしか手に入らない
- カードを消費すれば強力な効果を得るが、コンプから遠ざかる
- 同じエリアにいないとStealできない
- AIエージェントがx402で情報を売買する

**コアエクスペリエンス**:
「あと1枚でコンプ。遺跡に行けば手に入る。でもあいつも遺跡にいるかもしれない。移動すればターンを1つ失う。ここで待つか、賭けるか。」

## 3. マップシステム

### 3.1 三つのエリア

| エリア | 入手できるカード | 特徴 |
|--------|----------------|------|
| **港町 (Port)** | Crystal, Shadow | 安全地帯。NPC、情報屋、カードショップ。エンカウントなし |
| **深い森 (Forest)** | Flame, Storm | 背の高い草でランダムドロップ。エンカウント多い |
| **古代遺跡 (Ruins)** | Void, Crystal | レアドロップ。暗い、危険。宝物スポットあり |

**コンプするには全エリアを回る必要がある。**

### 3.2 Fog of War（Dark Forest式）

- **マップは最初真っ暗。歩いた場所だけ見える**
- 一度歩いた場所は記憶される（マップが徐々に開く）
- **他プレイヤーの位置は見えない**
- 同じタイルに入った瞬間だけ、相手の存在が分かる → エンカウント
- エリア間の出入りは公開情報にしない

### 3.3 移動の戦略性

- **「Move」がアクションの1つ**
- Moveを選んだターンは他のアクションができない
- 1ターンで隣接エリアに1つ移動
- → 「今動くべきか、ここで集め続けるべきか」のジレンマ

## 4. アクションシステム

### 4.1 アクション一覧（各ターン1つ選択）

| アクション | 効果 | 条件 | エリア制約 |
|-----------|------|------|-----------|
| **Draw** | 現在エリアのプールからランダム1枚 | 無制限 | 現在エリアのカードのみ |
| **Steal** | 対象の手札からランダム1枚 | 3回 | **同じエリアにいる相手のみ** |
| **Barrier** | Stealを防御 | 2回 | なし |
| **Scout** | 対象の手札 + **居場所**を確認 | 1回 | なし（どこからでも使える） |
| **Move** | 隣接エリアに移動 | 無制限 | — |
| **Use Card** | カードを消費して効果発動 | 該当カード所持 | カードによる |

### 4.2 カード消費効果

| カード | 消費効果 | エリア制約 |
|--------|---------|-----------|
| **Crystal** | 次のStealが確定成功（Barrier貫通） | 同エリアの相手のみ |
| **Shadow** | 1ターン完全不可視（Steal/Scout/Flame無効） | なし |
| **Flame** | 対象のカード1枚を焼却 | **同エリアの相手のみ** |
| **Storm** | 全員のBarrierを無効化 | なし（全エリアに効果） |
| **Void** | 対象のカード1枚をコピー | **同エリアの相手のみ** |

### 4.3 解決順序

1. **Move** — エリア移動（最初に処理、移動後の位置でSteal等が判定される）
2. **Shadow** — 不可視化
3. **Storm** — Barrier無効化
4. **Barrier** — Steal防御
5. **Steal / Crystal** — カード奪取
6. **Flame** — カード焼却
7. **Scout** — 手札 + 位置確認
8. **Draw** — プールから獲得
9. **Void** — カードコピー

## 5. ZK設計（Dark Forest + Commit-Reveal）

### 5.1 秘匿される情報

| 情報 | 秘匿方法 | 公開される条件 |
|------|----------|--------------|
| 手持ちカード | ZK commit-reveal | Scout呪文 / トレード時の開示 |
| 現在のエリア | ZK commit-reveal | Scout呪文 / 同エリアでのエンカウント |
| 選択したアクション | commit hash | Reveal時に公開 |

### 5.2 公開される情報（メタゲーム材料）

- 呪文使用履歴（誰が何をいつ使ったか）
- カード消費履歴（誰がどのカードを消費したか）
- 各プレイヤーの手札枚数（種類は不明）
- 各エリアのプール残数
- Move履歴（「誰かがMoveした」は分かるが「どこへ」は不明）

### 5.3 推理の深まり

- 「AがDrawした → Aは今いるエリアのカードを引いた → でもどのエリアにいるか不明」
- 「BがStealした → Bは誰かと同じエリアにいる」
- 「CがMoveした → Cはエリアを変えた → 次のターン、Cがいたエリアにはもういない」
- 「Aが3回連続Draw → 同じエリアにい続けてる → そのエリアのカードを集めてる」
- 「プール残数: 港町Crystal 0枚 → 誰かがCrystalを全部引いた → 港町にいた人は…」

| サービス | 価格 | 説明 |
|---------|------|------|
| 位置情報 | $0.002 | 「Player Bは今 Forest にいる」 |
| 手札情報 | $0.003 | 「Player Cは Crystal と Flame を持っている」 |

- 「強い偵察エージェント」「交渉特化エージェント」が市場で売買される
- エージェントの戦略はZKで秘匿

## 10. ゲームの1ラウンドの流れ

```
1. 全プレイヤーが秘密裏にアクションを選択
   - 「Draw（森でFlameを引く）」
   - 「Steal（同エリアの相手を狙う）」
   - 「Move（遺跡に移動する）」
   
2. Commit: action + target + エリア情報のハッシュをオンチェーンに提出

3. 全員Commit後、Reveal: アクション公開 + ZK証明提出

4. 解決（Move → Shadow → Storm → Barrier → Steal → Flame → Scout → Draw → Void）

5. 結果がオンチェーンに記録
   - 「Player A drew Flame from Forest」
   - 「Player B's Steal failed (different area)」
   - 「Player C moved to Ruins」

6. 勝利判定 → 次のラウンドへ
```
