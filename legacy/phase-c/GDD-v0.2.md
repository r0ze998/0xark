# 0xARK — Game Design Document v0.2 (Solana Frontier)

> **触って面白い最小限のものを、ブレないビジョンで磨く。説明しない、足さない、削る。**

---

## 1. コンセプト

**一言**: ZKで手札を隠した、カード奪い合いPvPゲーム on Solana

**エレベーターピッチ**:
3人のプレイヤーが島に放り込まれる。5種のカードを全て集めればクリア。カードはDrawで引くか、Stealで奪う。ただし誰が何を持っているかは見えない（ZK）。カードは「持ち続けてコンプを狙う」か「消費して強力な効果を発動する」かのジレンマが常にある。AIエージェントがx402マイクロペイメントで情報を売買し、オフライン中も戦略を実行する。

**コアエクスペリエンス**:
「あと1枚でコンプ。でもあいつに奪われるかもしれない。このカードを使えば守れるが、使ったらコンプから遠ざかる。」

---

## 2. 設計哲学

### GIの本質を抽出する
グリードアイランドの面白さ = カード収集のジレンマ + 情報の非対称性 + メタゲーム。これをオンチェーンで最小限に再現する。

### ピッチファースト
ハッカソンで勝つために: 先にピッチを書き、全ての主張を5週間で真にする。

### 削る基準
「この機能がなくても、カード奪い合いの緊張感は成立するか？」→ Yesなら削る。

---

## 3. コアループ

```
ラウンド開始
  ↓
全員が秘密裏にアクションを選択（Commit）
  ↓
全員が同時に公開（Reveal）
  ↓
解決: Barrier → Steal → Scout → Draw → カード消費効果
  ↓
勝利判定
  ↓
次のラウンドへ
```

**1ゲーム**: 15〜25ラウンド、約10〜15分

---

## 4. プレイヤー

- **人数**: 3人（2人だと読み合いが浅い。3人で同盟と裏切りが生まれる）
- **初期手札**: ランダム2枚（プールから配布）
- **初期呪文**: Steal ×3、Barrier ×2、Scout ×1
- **所持上限**: 5スロット（各カード種1枚ずつ）

---

## 5. カードシステム

### 5.1 コレクションカード（5種）

各カードは2つの使い方がある: **持つ**（コンプに近づく）か **消費する**（強力な効果を発動）。

| カード | 消費効果 | 戦略的意味 |
|--------|---------|-----------|
| **Crystal** 💎 | 次のStealが確定成功（Barrierも貫通） | 攻撃の切り札。使えばコンプから遠ざかる |
| **Shadow** 🌑 | 1ターン完全不可視（Steal/Scout無効） | 究極の防御。コンプ直前に使いたい |
| **Flame** 🔥 | 対象のカード1枚を焼却（消滅） | 妨害。相手のコンプを阻止 |
| **Storm** ⚡ | 全員のBarrierを無効化（このターン） | Steal連携の起点。同盟プレイで真価 |
| **Void** 🌀 | 対象のカード1枚をコピー（自分に追加） | コンプ加速。ただし元のカードは消える |

### 5.2 カードプール

| カード種 | プール枚数 | 希少性 |
|---------|-----------|--------|
| Crystal | 3枚 | 標準 |
| Shadow | 2枚 | やや希少 |
| Flame | 3枚 | 標準 |
| Storm | 3枚 | 標準 |
| Void | 2枚 | やや希少 |

**プール合計**: 13枚（3人 × 初期2枚 = 6枚配布、残り7枚）

### 5.3 カード消費のジレンマ

- カードを消費すると手札から消える → コンプから遠ざかる
- でも消費しないと攻撃に対して無防備
- 「いつ、何を消費するか」がゲームの最も重要な判断
- 消費した事実はオンチェーンで公開 → 相手に情報を与える

## 6. 呪文（アクション）

各ラウンド、プレイヤーは以下から1つ選んでCommit:

### 基本アクション

| アクション | 効果 | 回数制限 | 対象指定 |
|-----------|------|---------|---------|
| **Draw** | プールからランダム1枚獲得 | 無制限 | なし |
| **Steal** | 対象の手札からランダム1枚奪取 | 3回 | 要 |
| **Barrier** | このターンのStealを無効化 | 2回 | なし |
| **Scout** | 対象の手札を全て確認 | 1回 | 要 |

### カード消費アクション（追加）

| アクション | 効果 | 条件 |
|-----------|------|------|
| **Use Crystal** | 次のSteal確定成功 | Crystalを所持 |
| **Use Shadow** | 1ターン不可視 | Shadowを所持 |
| **Use Flame** | 対象のカード1枚焼却 | Flameを所持、対象指定 |
| **Use Storm** | 全Barrier無効化 | Stormを所持 |
| **Use Void** | 対象のカード1枚コピー | Voidを所持、対象指定 |

**1ターンに選べるのは1アクション**。呪文とカード消費は同時にできない。

### 解決順序

1. **Shadow** — 不可視化（以降のSteal/Scout/Flameの対象から外れる）
2. **Storm** — Barrier無効化
3. **Barrier** — Steal防御（Stormで無効化されていなければ）
4. **Steal** — カード奪取（Crystal使用時は確定成功）
5. **Flame** — カード焼却
6. **Scout** — 手札確認
7. **Draw** — プールから獲得
8. **Void** — カードコピー

---

## 7. 勝利条件

| 条件 | 説明 |
|------|------|
| **コンプリート** | 5種全てのカードを所持 → 即時勝利 |
| **タイムアップ** | 25ラウンド終了時、最多ユニークカード種を持つプレイヤー |
| **殲滅** | 他の全プレイヤーがカード0枚 |

**同数の場合**: 合計カード枚数 → それも同数ならラウンド数（先に集めた方が勝ち）

## 8. ZK（情報秘匿）

### Commit-Reveal（Circom + Groth16）

1. プレイヤーがアクションを選択
2. `hash = Poseidon(action_type, target, salt)` をオンチェーンにCommit
3. 全員Commit後、Reveal: action_type, target, salt + Groth16証明を提出
4. オンチェーンで証明検証（200K CU以下）→ 解決

### 公開される情報（メタゲーム材料）

- 呪文使用履歴（誰が何をいつ使ったか）
- カード消費履歴（誰がどのカードを消費したか）
- 各プレイヤーの手札枚数（種類は不明）
- プール残数

### 秘匿される情報

- 手札の内容（何を持っているか）
- Commitしたアクション（Revealまで）

### メタゲームの発生

公開情報から推理する:
- 「AがStealを3回使い切った → Aはもう奪えない」
- 「BがShadow消費した → Shadowは持ってない = コンプから1つ遠い」
- 「Cの手札が4枚ある → リーチの可能性。潰すべきか？」
- 「プールにShadowが0枚 → 誰かが2枚持ってる」

## 9. AI Agent経済圏（x402）

### エージェントの役割

各プレイヤーはAIエージェントを設定できる（オプション）:
- オフライン時の自動プレイ
- 戦略プロンプトに基づく意思決定
- x402マイクロペイメントでの情報売買

### x402情報マーケット

| サービス | 価格目安 | 説明 |
|---------|---------|------|
| 偵察結果の販売 | $0.001 | 「Player Bはカード3を持っている」 |
| 戦略アドバイス | $0.005 | 「現在の最適行動はBarrier」 |
| 偽情報 | $0.001 | 嘘の偵察結果を販売（リスクあり） |
| 同盟提案 | $0.01 | 「次のターン、一緒にCを狙おう」 |

### なぜx402か

- HTTP 402 → エージェントがAPIコールごとに自動支払い
- USDC on Solana → $0.00025 TX手数料 → 真のマイクロペイメント
- サブスク不要、アカウント不要 → エージェントが自律的に決済

## 12. Phase 1 スコープ（Frontier提出用）

### 入れるもの
- 3人プレイ

- MagicBlock Ephemeral Rollups

## 13. 面白さの判定基準

1. **「もう1回やりたい」** と思えるか
2. **カードを消費する判断** で悩むか
3. **相手の行動を読む** 楽しさがあるか
4. **3人の力学** （同盟と裏切り）が生まれるか
5. **AIエージェント** の行動が人間とは違う面白さを生むか
